## 为什么这个测试重要

`.XUQIAN` 的头部与分块布局由 `src/crypto/container.ts` 唯一定义。浏览器与命令行两端
**共用同一份加密实现**（CLI 直接 import `src/crypto/*`，依赖 Node ≥20 的 `crypto.subtle`），
因此本测试验证的是"同一实现对同一格式的读写一致"，而不是两套独立实现的偶然兼容。
