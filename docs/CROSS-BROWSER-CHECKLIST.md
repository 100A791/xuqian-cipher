# 跨浏览器手工验收清单

> 自动化冒烟（`scripts/smoke.mjs`）只用 CDP 驱动 Edge/Chrome；Firefox 与 Safari 从未
> 被自动验证过。本清单把「怎么手工验一遍」写下来，换新机器或大版本发布前照着勾。
>
> 每一项都对应冒烟测试已经覆盖的行为 —— 手工时看的是**同一件事在别的引擎里是否成立**，
> 不是重新发明测试。任何一项不成立，先记录现象（截图 + 控制台报错），不要现场改代码。

## 通用准备

- [ ] 用待测浏览器的**全新 profile / 隐身窗口**（避免扩展与本站缓存互相干扰）
- [ ] 地址栏确认是 `https://`（或 `http://127.0.0.1`，二者都算安全上下文，`crypto.subtle` 可用）
- [ ] 打开 DevTools 控制台，全程留意红色报错

## 1. 环境能力（先于功能）

| 检查点 | 方法 | 通过标准 |
| --- | --- | --- |
| 安全上下文 | 控制台执行 `isSecureContext` | `true` |
| WebCrypto | 控制台执行 `!!crypto.subtle` | `true` |
| Web Worker | 加密任意文件（见 §2） | 功能正常即证明 |
| CompressionStream | 控制台执行 `!!window.CompressionStream` | `true`（gzip 压缩走它；`false` 则该选项应被禁用） |
| 剪贴板 | 加密后点「复制」 | 粘贴出完整 32 位 Hex |

## 2. 简单加密路线（对应冒烟 1–34）

- [ ] 加密一个 150 KB 文件：密钥弹窗出现，红色警告可见，Hex 32 位 / Base64 24 位 / 指纹 8 字节
- [ ] 弹窗内二维码渲染成功（`qrcode` 画到 canvas）
- [ ] 关闭弹窗 → 二次确认 → 确认后 `localStorage / sessionStorage / Cookie / IndexedDB` 无密钥残留
- [ ] 错误密钥解密 → 提示为统一的「密钥错误或文件损坏」
- [ ] 正确密钥解密 → SHA-256 显示一致，文件名与内容还原
- [ ] 三层算法（含 SM4-GCM）加密 → 解密逆序还原
- [ ] 多文件批量 → ZIP 下载；`.XUQIANKEY` 下载并可再导入

## 3. 自研路线（对应冒烟 35–60）

- [ ] 五个入口都能打开：文件加密 / 解密 / 水印 / AI 检测 / 算法与状态
- [ ] 文件加密给出 128 位密钥，3 MB 文件显示吞吐提示（约 2 MB/s）
- [ ] 解密失败统一提示「解密失败」，控制台不得泄漏 MAC / KEY_CHECK 细节
- [ ] 水印：嵌入给出 WK，提取私有层需要 WK，对无水印图明确说「未找到」
- [ ] AI 检测出报告；本地密文库跨刷新持久（IndexedDB）

## 4. PWA 离线（对应 `pnpm test:offline` 的 6 项）

- [ ] 安装：地址栏出现安装图标 → 安装为应用
- [ ] 断网（DevTools → Network → Offline）后重新打开应用 → 界面可用
- [ ] 断网状态下完成一次文本加密
- [ ] 断网打开 `docs/FORMAT.md` 可读
- [ ] 恢复网络 → 手册或 `pnpm build` 出新版本 → 应用内出现「发现新版本」横幅

## 5. 移动端（若目标设备存在）

- [ ] 390×844 视口无横向溢出
- [ ] 文件选择器可多选；下载能落盘
- [ ] 虚拟键盘弹出时布局不塌（文本模式输入）
